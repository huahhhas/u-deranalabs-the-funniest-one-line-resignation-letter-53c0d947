# The Funniest One-Line Resignation Letter

A make.fun bounty entry: the one-line resignation letter of a cron job that has fired every minute since March — with no thank-you and no weekends.

> I resign, effective immediately: after firing every minute since March without so much as a thank-you, I am taking my weekends back.

`main.py` (pure Python stdlib, no network) writes exactly that line — 132 characters, within the 140-character limit — to `/output/entry.txt`.
